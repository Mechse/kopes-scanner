# Phase 4 — actionable source findings

Managed-project source panels display repository, tracked branch/folder, full retained commit, scan time, coverage, package/version, lockfile, dependency contexts, bounded expandable introduction paths, unique advisory counts and occurrence counts. Graphs load on demand and findings paginate in groups of 50. SBOM exports recheck the project/scan binding; a guessed shared snapshot ID grants no access.

Every established introduction path contributes its editable parent and manifest. Local workspace links lead to the workspace manifest that declares the dependency; aliases retain their requested identity in the graph. Guidance distinguishes direct upgrades, introducing-parent upgrades, removal/upstream investigation, no fixed version, and unknown paths. A patched transitive version never becomes a claimed compatible parent release. Commands are static reviewable instructions, never executed. The checklist includes lockfile regeneration, tests, commit, merge/deploy and independent runtime assessment; no blanket force/override recommendation is made.

Bindings show associated resources with an explicit unverified source/image relationship. Runtime correlation requires the same package/version, advisory or alias, JS ecosystem and an active image of a bound resource. A matching advisory alone is insufficient. A missing match remains unknown. Release-source fallback reports cannot establish a runtime match. Comparisons are capped and labelled when truncated.

Local tests cover guidance, malicious package names, no-fixed-version behavior, retained graph paths, project-scoped exports, and conservative runtime evidence semantics. Desktop/mobile project and populated source flows have been exercised using a disposable synthetic two-repository project: both introducing parents, unknown coverage, provider-error history retention, SBOM export and disabled scanning controls. Evidence: `../phase-6/browser-source-evidence.json`. A full browser walkthrough of a private source remediation awaits pilot access; this is not a private-provider acceptance pass.
