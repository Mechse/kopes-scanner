L187: # Docsec - Container Image Vulnerability and Management Platform
L188: 
L189: DocSec is a container security dashboard built around Trivy. It provides:
L190: 
L191:   * automated image vulnerability scanning
L192:   * manual image scanning
L193:   * SBOM browsing
L194:   * CVE trend charts
L195:   * CVSS enrichment from NVD
L196: ## Tech Stack
L197: 
L198:   * Frontend: React + TypeScript + Vite
L199:   * Backend: Go
L200:   * Scanner: Trivy server mode
L201:   * Metrics: Prometheus
L202:   * Runtime: Docker Compose
L203: 
L204: ## Prerequisites
L205: 
L206:   * Docker Desktop (or Docker Engine + Docker Compose v2)
L207:   * Git
L208: 
L209: ## Project Structure
L210: 
L211:   * `frontend/`: UI application
L212:   * `backend/`: API, scan orchestration, auth, SBOM/CVE processing
L213:   * `docker-compose.yml`: multi-service setup
L214:   * `.env`: runtime/build configuration for the stack
L215: ## Environment Configuration
L216: 
L217: Create or edit the root `.env` file.
L218: Current variables:
L219: 
L220:     # Backend service
L221:     BACKEND_ADDR=:8081
L222:     TRIVY_SERVER=http://trivy:8088
L223:     MANUAL_REPORTS_DIR=/data/manual-reports
L224:     SCAN_INTERVAL=30s
L225:     DOCKER_HOST=unix:///var/run/docker.sock
L226: 
L227:     # Auth / JWT
L228:     AUTH_USERNAME=change-me
L229:     AUTH_PASSWORD=change-me
L230:     AUTH_JWT_SECRET=replace-with-a-random-32-char-min-secret
L231:     AUTH_TOKEN_TTL=1h
L232:     AUTH_JWT_ISSUER=trivy-uo
L233: 
L234:     # Security controls
L235:     CORS_ALLOWED_ORIGINS=http://localhost:3033
L236:     # Empty disables user-supplied authUrl for manual scans.
L237:     TRIVY_ALLOWED_AUTH_HOSTS=
L238: 
L239:     # NVD enrichment (optional API key)
L240:     NVD_API_URL=https://services.nvd.nist.gov/rest/json/cves/2.0
L241:     NVD_API_KEY=
L242: 
L243:     # Frontend chart default window: one of 1m, 10m, 1h, 24h, 1mo
L244:     VITE_DEFAULT_TREND_WINDOW=1mo
L245: Notes:
L246: 
L247:   * `AUTH_USERNAME`, `AUTH_PASSWORD`, and `AUTH_JWT_SECRET` are required at startup.
L248:   * `AUTH_JWT_SECRET` must be at least 32 characters.
L249:   * `NVD_API_KEY` is optional but recommended for higher NVD API throughput.
L250:   * `VITE_DEFAULT_TREND_WINDOW` is used at frontend build time. Rebuild frontend after changing it.
L251:   * `CORS_ALLOWED_ORIGINS` should only include trusted frontend origins.
L252:   * Keep `TRIVY_ALLOWED_AUTH_HOSTS` empty unless you explicitly need registry auth URLs for manual scans.
L253: ## Installation and Run (Docker)
L254: 
L255:   1. Clone the repository and move into it.
L256: 
L257:     git clone <your-repo-url>
L258:     cd docsec
L259: 
L260:   2. Ensure the external Docker network exists (required by `docker-compose.yml`).
L261: 
L262:     docker network create pangolin
L263: 
L264:   3. Review/update `.env` in the project root.
L265: 
L266:   4. Build and start all services.
L267: 
L268:     docker compose up -d --build
L269: 
L270:   5. Verify service configuration.
L271: 
L272:     docker compose config
L273: ## Access
L274: 
L275:   * Frontend: `http://localhost:3033`
L276:   * Backend API: `http://localhost:8081`
L277:   * Trivy server: `http://localhost:8088`
L278:   * Prometheus: `http://localhost:9099`
L279: 
L280: Login:
L281: 
L282:   * username: value of `AUTH_USERNAME`
L283:   * password: value of `AUTH_PASSWORD`
L284: ## Common Commands
L285: 
L286:     # Stop services
L287:     docker compose down
L288: 
L289:     # Stop services and remove volumes
L290:     docker compose down -v
L291: 
L292:     # View logs
L293:     docker compose logs -f
L294: 
L295:     # Rebuild only frontend (needed after VITE_DEFAULT_TREND_WINDOW change)
L296:     docker compose up -d --build frontend
L297: 
L298: ## Development (Frontend only)
L299: 
L300:     npm install
L301:     npm run dev
L302: 
L303: This runs the frontend dev server from the root package scripts.
