# PatchMon — quick competitor profile

Researched: 2026-11-08. Category: Adjacent: host patch management.

## Observed product and pricing

Agent-based fleet inventory and package patching, approvals, schedules, patch history, Docker inventory and compliance checks. Its architecture includes PostgreSQL and Redis.

Free AGPL-3.0 self-hosting. Cloud Starter $1, Plus $2, Max $3 per host/month at monthly billing; no minimum host count. Docker monitoring starts at Plus; compliance at Max.

Sources: [Source 1](https://github.com/PatchMon/PatchMon), [Source 2](https://patchmon.net/pricing).

## Interpretation for Kopes

Strong overlap with host maintenance, and a low hosted price anchor. Docker monitoring is not proof of image CVE scanning; that equivalence was not established. Kopes might appeal to users seeking visibility without patch execution.

## Limits

Documentation research only; no installation or performance comparison. Traffic, market share, funding, customer counts and review scores were not assessed. No SEO data provider was available for this research. Missing documented features are not confirmed absences.
