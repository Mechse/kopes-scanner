# Wazuh — quick competitor profile

Researched: 2026-11-08. Category: Adjacent: host security platform.

## Observed product and pricing

Agents collect OS and installed-package inventory. Server-side vulnerability detection correlates inventory with vulnerability intelligence. The wider product covers threat prevention, detection and response.

Free and open source self-hosting. Hosted pricing was not verified; pricing/product URL requests failed.

Sources: [Source 1](https://documentation.wazuh.com/current/user-manual/capabilities/vulnerability-detection/how-it-works.html), [Source 2](https://github.com/wazuh/wazuh).

## Interpretation for Kopes

A serious alternative when users need broader host security. Do not assume Docker event monitoring equals container-image package scanning. Kopes' simpler single-host operation is a hypothesis to test, not a benchmarked advantage.

## Limits

Documentation research only; no installation or performance comparison. Traffic, market share, funding, customer counts and review scores were not assessed. No SEO data provider was available for this research. Missing documented features are not confirmed absences.
