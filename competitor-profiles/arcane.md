# Arcane — quick competitor profile

Researched: 2026-11-08. Category: Direct: Docker operators.

## Observed product and pricing

Scheduled Trivy scans, fixable filters, CVE trends, KEV/EPSS risk signals and Copacetic OS-package image patching. Patching produces a new local tag; the user must redeploy. Application dependencies are excluded from patching.

Free, BSD-3-Clause open source.

Sources: [Source 1](https://getarcane.app/docs/security/vulnerability-scans), [Source 2](https://github.com/getarcaneapp/arcane).

## Interpretation for Kopes

High competitive relevance: security is bundled into a Docker management tool. Test whether people already using Coolify prefer a separate scanner to another management interface.

## Limits

Documentation research only; no installation or performance comparison. Traffic, market share, funding, customer counts and review scores were not assessed. No SEO data provider was available for this research. Missing documented features are not confirmed absences.
