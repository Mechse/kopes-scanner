# OWASP Dependency-Track — quick competitor profile

Researched: 2026-11-08. Category: Adjacent: SBOM portfolio monitoring.

## Observed product and pricing

Ingests CycloneDX SBOMs, continuously analyzes component risk, prioritizes with EPSS, applies policies and sends notifications. Producers supply SBOMs via API, CI or UI.

Free and open source.

Sources: [Source 1](https://dependencytrack.org/).

## Interpretation for Kopes

An alternative for teams willing to build an SBOM pipeline; possible integration destination for Kopes. Its documented input model differs from automatically discovering local Docker resources.

## Limits

Documentation research only; no installation or performance comparison. Traffic, market share, funding, customer counts and review scores were not assessed. No SEO data provider was available for this research. Missing documented features are not confirmed absences.
