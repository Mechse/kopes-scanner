# DOCSEC — quick competitor profile

Researched: 2026-11-08. Category: Direct: dedicated self-hosted scanner.

## Observed product and pricing

Trivy-based dashboard with automated/manual image scanning, SBOM browsing and CVE trends. Documented stack has frontend, backend, Trivy and Prometheus containers.

Free, GPL-3.0 open source.

Sources: [Source 1](https://github.com/AneezHussain/docsec).

Very close product concept. Compare installation, scan changes and remediation clarity hands-on. Host OS package scanning was not established by the README reviewed.
